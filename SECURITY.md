# Security policy

## Reporting a vulnerability
Please **do not** open a public issue for a security problem. Report it privately through GitHub: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the app version or commit. We will acknowledge your report, keep you updated, and credit you in the fix if you wish.

Please don't access other people's data, degrade the service, or run automated scanners against production while testing.

## Scope
- The Android app and its source code in this repository.
- The backend that this repository configures (database policies, functions and storage rules).

Deals and offers come from third parties. Report a wrong or misleading deal in the app instead.

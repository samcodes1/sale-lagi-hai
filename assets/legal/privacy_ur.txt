# رازداری کی پالیسی
آخری بار اپ ڈیٹ: 29 اکتوبر 2026

سیل لگی ہے! پورے پاکستان کی ڈیلز دکھاتی ہے۔ ہم کم سے کم معلومات لیتے ہیں، اور آپ کا ڈیٹا کبھی نہیں بیچتے۔

# اکاؤنٹ کے بغیر
- آپ کی زبان، شہر، دلچسپیاں، فالو کیے ہوئے برانڈز اور زمرے، محفوظ کردہ ڈیلز، حالیہ تلاش اور کارڈز اسی فون پر رہتے ہیں۔
- جب آپ اپنے قریب کی ڈیلز دیکھتے ہیں، تو آپ کا اندازاً مقام صرف اسی تلاش کے لیے استعمال ہوتا ہے۔ اسے کبھی محفوظ نہیں کیا جاتا۔
- ہم کبھی کارڈ نمبر نہیں مانگتے۔ "میرے کارڈز" میں صرف آپ کا بینک اور کارڈ کی قسم محفوظ ہوتی ہے۔

# اکاؤنٹ کے ساتھ
- آپ اپنے موبائل نمبر (ایس ایم ایس کوڈ) یا گوگل سے سائن اِن کرتے ہیں۔ ہم آپ کا نمبر یا ای میل صرف سائن اِن کے لیے رکھتے ہیں۔
- اوپر دی گئی آپ کی پسند آپ کے اکاؤنٹ میں بھی رہتی ہے، تاکہ دوسرے فون پر بھی ملے۔
- اگر آپ الرٹس آن کریں، تو ہم انہیں بھیجنے کے لیے آپ کے فون کا نوٹیفکیشن ٹوکن اور آپ کی الرٹ سیٹنگز رکھتے ہیں۔

# ہم کبھی نہیں کرتے
- ہم آپ کا ڈیٹا کبھی نہیں بیچتے، نہ کرائے پر دیتے ہیں، نہ برانڈز کو دکھاتے ہیں۔
- ہم کبھی کارڈ نمبر، پن، سی وی وی یا دوسری سروسز کے پاس ورڈ نہیں مانگتے۔
- برانڈز صرف مجموعی تعداد دیکھتے ہیں، یہ نہیں کہ آپ کون ہیں۔

# اپنا ڈیٹا حذف کرنا
- پروفائل، اکاؤنٹ ڈیلیٹ کریں سے آپ کا اکاؤنٹ اور اس میں موجود سب کچھ فوراً ختم ہو جاتا ہے۔ یہ فون بھی صاف ہو جاتا ہے۔
- سیٹنگز، رازداری سے آپ کسی بھی وقت اس فون پر محفوظ معلومات صاف کر سکتے ہیں۔

# سوالات
گوگل پلے پر ہمارے صفحے پر دیے گئے ای میل پر ہمیں لکھیں، یا سیٹنگز، تعارف سے، اگر ایپ کا یہ ورژن وہاں رابطے کا پتا دکھاتا ہے۔
